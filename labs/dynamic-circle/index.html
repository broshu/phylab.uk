Dynamic Circles: how it works

Path radius

The Lorentz force provides the centripetal force:

The radius is set by the speed alone. If the speed stays the same, all the path circles have the same size.

Three kinds of dynamic circle

Translating circle: the speed and direction are the same but the entry points differ. The centres lie on a straight line and the circle simply shifts as a whole.

Rotating circle: the entry point and the speed are the same but the directions differ. The centres lie on a circle of radius R around the entry point, and the path circle rotates about the entry point.

Expanding circle: the entry point and the direction are the same but the speeds differ. The centres lie on the line through the entry point perpendicular to the velocity, and the circle grows larger and larger.

Approach

First decide which kind of dynamic circle applies, then draw a few representative path circles, find the critical state where the path touches the boundary, and use geometry to find the radius or the range.
