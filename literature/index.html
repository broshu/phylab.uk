How this library is curated

优先收录能帮助区分概念理解、实验能力与独立迁移的文献。保留经典理论与评估工具，同时关注近期研究；不追求每周凑数。PhD Core 表示研究设计或理论框架的优先阅读文献，Read 表示值得全文阅读，Skim 表示背景参考。

推荐经来源核对后追加，页面随文献库更新。已收录范围不是系统综述；短期成绩、认知负荷和自我报告不能自动等同于真实实验能力或长期迁移。每条推荐注明核对来源与证据边界。
